# Asian-Tarot-Deck-Builder

## Introduction
This project is a Python-based tool designed to automatically generate Midjourney prompts for a 64-card I Ching-inspired tarot deck and to systematically manage key text data for each card.

## Key Features
- Integrated management and CSV linking of data covering the 64 I Ching hexagrams, Rider-Waite meanings, and Korean proverbs.
- Automated assembly and batch extraction of English Midjourney prompts for card artwork (featuring styles such as Ukiyo-e and Art Nouveau).
- Automated alignment of text layout data for printing the card deck.
